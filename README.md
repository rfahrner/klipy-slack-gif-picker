# KLIPY Slack GIF Picker

A Tenor-style Slack GIF picker powered exclusively by KLIPY.

## Planned UX
- KLIPY only; no GIPHY.
- Open to recently used GIFs.
- Search for GIFs.
- Load 20 results initially.
- Infinite scroll loads the next 20 automatically.
- Click a GIF for a 2x preview before selecting.
- Selected GIF should remain pending until the user sends it.
- Per-user recent GIF history.

## Development
This repository is being built incrementally. Secrets belong in local environment variables or GitHub/hosting secrets and must never be committed.
